# 待测试

## 商品套图工作台

- 新增 `/product-suite` 与顶部“商品套图”入口。
- `/`、画布、生图、视频、提示词、素材和工作流等旧用户入口统一重定向到 `/product-suite`；商品页面隐藏原“无限画布”顶部导航，成为独立产品。
- 默认页面采用“上传 1-4 张商品原图 → 一键生成整套 6 张 → 下载 ZIP”的极简 Agent 流程，不展示提示词、抠图、背景、版式和质检等内部概念。
- Agent 固定规划品牌主视觉、电商白底主图、真实使用场景、材质工艺特写、`3:2` 横版广告和 `2:3` 竖版社媒海报。
- 生成顺序固定为先品牌主视觉、再白底主图、场景、特写、横版和竖版；第 3-6 张同时引用商品原图和品牌主视觉，原图负责商品身份，主视觉只负责色彩、光影和表面语言。
- gotocc 单并发下按顺序生成，完成一张立即展示；失败项不会阻断后续任务，支持单张重试和停止未完成任务。
- 生成前显示整套 6 张、预计 8-12 分钟和预计 `$0.36`；已有结果时重新生成整套需二次确认。
- 商品原图与已完成结果自动保存到浏览器 IndexedDB，刷新后恢复；gotocc Key 仍单独保存在浏览器，不进入草稿。
- 每张结果支持独立下载与重新生成；整套 ZIP 使用固定图序、用途和画幅命名。
- 默认生成链路通过 gotocc `POST /v1/images/edits` 发送商品参考图，让 GPT Image 2 一次完成商品身份参考、场景、接触阴影和匹配光照；提示词强制要求保留结构、颜色、Logo、印刷、零件数量和左右方向。
- 图片编辑代理仅接受 GPT Image 2、1-4 张 JPEG/PNG/WebP、单张不超过 15 MB、总请求不超过 64 MB，并强制 `n=1` 与 `b64_json` 响应，避免任意转发和意外批量扣费。
- 原商品套图工作台仅从结果区“精修单张”进入，并提供“简易模式”返回入口。
- 商品原图默认使用本地 U2-NetP 分割，模型与 ONNX Runtime 静态资源自托管，图片不离开浏览器；保留白底快速提取作为兜底。
- 商品主体作为透明像素层参与合成，不传给生图模型，不允许镜像或重绘。
- GPT Image 2 只生成无商品、无文字的空背景。
- 提供机械、电子、家居、美妆、服饰、食品、玩具、珠宝和通用商品 9 类路由；每类按购买理由、细节、功能、核心场景、第二场景和白底图规划 6 个独立任务帧。
- 每个任务帧独立保存版式、文案、背景描述、商品位置和细节焦点，切换图序不会丢失编辑值。
- 提供三栏品牌主图、主体与细节、信息面板、沉浸场景、非对称留白和白底目录图六种确定性版式。
- 三栏主图固定为 `38 / 24 / 38`，文字由 Canvas 确定性渲染；可导出单张 2048 PNG，整套导出为包含 6 张 2048 PNG 的 ZIP。
- 支持连接用户自己的 gotocc `GPT image 2 生图分组` Key；Key 只保存在当前浏览器，后端只向固定 gotocc 生图接口转发 GPT Image 2 请求，不写入本站账号、数据库或日志。
- 商品上传后自动生成原图尺寸、透明主体尺寸、主体占比、主色与双哈希事实摘要，并按文件名中的明确关键词建议品类。
- 每张套图提供商品像素、方向与 Logo、抠图边缘、空背景、确定性文案和版式边界六项本地质检，支持对边缘、比例与偏移执行一键修复。
- 支持一次上传 1-5 张商品证据图并切换主商品图；单角度商品会在质检中明确限制未知角度，不把附加图片发送给背景模型。
- 商品档案、商品图、透明商品层、背景、文案、版式和品牌色会自动保存到浏览器 IndexedDB，刷新后恢复；gotocc Key 不进入项目草稿。
- 提供整套质检分数、待处理图数量、问题定位，以及保留文案内容的整套“带文案 / 无字版”切换。
- 美妆首图支持 `3:4` 奢华静物版式，玩具首图支持 `1464:600` A+ 横幅版式；其他任务继续使用方图，导出文件名包含实际画幅。
- 摩托车、毛绒玩具和口红示例用于跨品类验收商品方向、边缘提取、文案、版式和 2048 导出，不会上传测试素材。
