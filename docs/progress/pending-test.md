# 待测试

## 商品套图工作台

- `/`、画布、生图、视频、提示词、素材和工作流等旧用户入口统一重定向到 `/product-suite`；商品页面隐藏原“无限画布”顶部导航，成为独立产品。
- 默认流程为“上传/追加 1-5 张多视角白底图或实拍图 → 填写可选商品事实和市场/品牌设置 → 选择生成类型 → 开始生成 → 单张处理或完整 ZIP”。
- 8 张固定覆盖电商白底主图、品牌主视觉、核心卖点图、真实使用场景、材质工艺特写、A+ 内容图、`3:2` 横版广告和 `2:3` 竖版社媒海报。
- 白底主图遵循平台目录规范；品牌主视觉至竖版海报共享同一 Visual DNA，并把主视觉原图作为后续 6 张的风格参考。主视觉失败会暂停依赖任务，主视觉更新会使旧下游图失效。
- 选择任一后续营销图会自动带上品牌主视觉；商品原图始终是 SKU、几何、颜色和 Logo 权威，主视觉只负责光向、阴影、色温、材质、道具和后期质感。
- 商品场景按品类规划：玩偶进入卧室/游戏区，扫地机器人落在卧室或客厅地面，礼服进入宴会/酒店，咖啡机进入厨房台面或咖啡馆；未知品类由模型根据商品图选择真实使用环境，禁止无关奢华展台。
- 品牌颜色提供智能推荐、高级黑、科技蓝、活力红、自然绿、温暖橙和系统取色器；颜色只作为整套点缀色。
- 参考图先经本地商品主体分析过滤明显异 SKU，再按任务选择主图、匹配角度图并生成同 SKU 联系表；单张分析失败只隔离该文件，不再让全部有效多视角退化。
- 卖点图和 A+ 图由 Canvas 确定性渲染用户提供的商品事实；未填写时只使用“可见结构/原图信息”等非营销声明。
- 本地尺寸、成像、颜色、结构、OCR、白底和重复商品检查只记录技术信息；不会因构图、风格、镜头相似或检查失败拒绝已返回图片，也不会自动产生第二次付费请求。
- 每张完成卡和错误卡都有文字明确的“重新生成”；用户也可主动填写问题做定向返修。所有单图付费请求显示约 `$0.08` 并二次确认。
- 停止、刷新、超时、网络中断或代理 POST 传输失败会持久化独立的“上游状态未知”标记，确认 gotocc 记录前不能再次付费；上游已返回的图片会继续完成本地保存，不因停止后处理而丢失。
- 修改商品信息或市场/品牌设置后，旧结果立即失效。
- 固定 8 张都已生成且存在结果时开放 ZIP；`warning` 或 `inconclusive` 不再阻止下载，未选择、未生成、生成失败和主视觉更新后的旧下游图仍会阻止。
- 商品原图、设置、技术检查和结果使用 `version: 7` 保存在浏览器 IndexedDB；每次付费请求前必须保存成功，否则请求不会发出。旧版自定义颜色和被旧质检拦截的已付费结果会迁移保留，gotocc Key 不进入草稿或历史。
- gotocc 当前实测单张约 `$0.08`，8 张基础费用约 `$0.64`；仅明确的 425/429 响应自动重试，网络中断、5xx、参数、鉴权、超时、空响应和图片读取失败不会自动重试。
- 后端图片编辑代理仅接受 GPT Image 2、1-4 张 JPEG/PNG/WebP、单张不超过 15 MB、总请求不超过 64 MB，并强制 `n=1` 与 `b64_json` 响应。
