# 待测试

## 商品套图工作台

- `/`、画布、生图、视频、提示词、素材和工作流等旧用户入口统一重定向到 `/product-suite`；商品页面隐藏原“无限画布”顶部导航，成为独立产品。
- 默认流程为“上传/追加 1-5 张多视角白底图或实拍图 → 填写可选商品事实和市场/品牌设置 → 选择生成类型 → 开始生成 → 单张处理或完整 ZIP”。
- 8 张固定覆盖电商白底主图、品牌主视觉、核心卖点图、真实使用场景、材质工艺特写、A+ 内容图、`3:2` 横版广告和 `2:3` 竖版社媒海报。
- 8 张使用不同镜头合同，主视觉失败不会阻断其他任务；主视觉后补成功时会免费回审已完成下游图片的整套风格。
- 参考图先经本地商品主体分析过滤明显异 SKU，再按任务选择主图、匹配角度图并生成同 SKU 联系表；单张分析失败只隔离该文件，不再让全部有效多视角退化。
- 卖点图和 A+ 图由 Canvas 确定性渲染用户提供的商品事实；未填写时只使用“可见结构/原图信息”等非营销声明。
- 卖点/A+ 文案叠加完成后，再对最终交付图执行精确像素尺寸、有效成像、商品主色、主体轮廓、内部标识与部件、镜像、白底规范、任务重复和整套风格检查；本地 OCR 额外拦截原图和用户卖点中不存在的高置信新文字。
- 硬性失败不标完成；只有尺寸、空白成像、陌生文字、白底规范或近乎完全重复等高置信失败可自动定向返修一次。结构、颜色、数量和机位启发式失败保留已付费原稿，必须由用户确认费用后返修。
- 主体结构检查使用浏览器本地 U2-NetP 分割；OCR/U2-Net 临时不可用时结果标记 `inconclusive`，不自动重复扣费，也不能进入完整 ZIP，可免费重新质检。
- 每张支持普通重生成、免费重新质检和定向返修；所有单图付费重试显示费用并二次确认。停止、刷新、超时、网络中断或代理 POST 传输失败会持久化独立的“上游状态未知”标记，免费质检不会清除，确认 gotocc 记录前不能再次付费。
- 修改商品信息或市场/品牌设置后，旧结果立即失效。
- 仅固定 8 张全部 `pass` 时开放 ZIP；少选任务、`warning`、`inconclusive`、停止、失败或历史未质检结果均不能作为整套下载。
- 商品原图、设置、质检报告和结果使用 `version: 7` 保存在浏览器 IndexedDB；每次付费请求前必须保存成功，否则请求不会发出。旧版已付费结果保留并提供免费新版质检，gotocc Key 不进入草稿或历史。
- gotocc 当前实测单张约 `$0.08`，8 张基础费用约 `$0.64`；仅明确的 425/429 响应自动重试，网络中断、5xx、参数、鉴权、超时、空响应和图片读取失败不会自动重试。
- 后端图片编辑代理仅接受 GPT Image 2、1-4 张 JPEG/PNG/WebP、单张不超过 15 MB、总请求不超过 64 MB，并强制 `n=1` 与 `b64_json` 响应。
