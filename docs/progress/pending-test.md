# 待测试

## 商品套图工作台

- `/`、画布、生图、视频、提示词、素材和工作流等旧用户入口统一重定向到 `/product-suite`；商品页面隐藏原“无限画布”顶部导航，成为独立产品。
- 默认流程为“上传 1-4 张商品原图 → 可选填写商品名称与真实卖点 → 一键生成整套 8 张 → 下载 ZIP”。
- 8 张固定覆盖品牌主视觉、电商白底主图、核心卖点图、真实使用场景、材质工艺特写、A+ 内容图、`3:2` 横版广告和 `2:3` 竖版社媒海报。
- 先生成品牌主视觉；场景、卖点、特写、A+、横版和竖版 6 张同时引用商品原图与主视觉，白底主图首稿只引用商品原图；主视觉失败时立即阻断后续任务，避免生成无统一风格的散图。
- 卖点图和 A+ 图由 Canvas 确定性渲染用户提供的商品事实；未填写时只使用“可见结构/原图信息”等非营销声明。
- 卖点/A+ 文案叠加完成后，再对最终交付图执行精确像素尺寸、有效成像、商品主色、主体轮廓、内部标识与部件、镜像、白底规范、任务重复和整套风格检查；本地 OCR 额外拦截原图和用户卖点中不存在的高置信新文字。
- 硬性失败不标完成；第二次请求会同时携带商品原图、品牌主视觉、失败稿和具体质检原因进行定向返修。
- 主体结构检查使用浏览器本地 U2-NetP 分割；模型或浏览器运行失败会作为硬错误，不能进入完整 ZIP。
- 每张支持普通重生成和定向返修；定向返修同时引用商品原图、品牌主视觉、当前结果和用户问题说明。
- 修改商品名称或卖点后，旧结果立即失效；重生成主视觉必须重做整套，避免新旧风格混用。
- 仅 8 张全部完成且无失败时开放 ZIP；停止、失败或历史未质检结果不能作为“整套”下载。
- 商品原图、卖点、质检报告和结果保存在浏览器 IndexedDB；旧版未质检草稿会标记重新生成，gotocc Key 不进入草稿。
- gotocc 当前实测单张约 `$0.08`，8 张基础费用约 `$0.64`；仅明确的 425/429 响应自动重试，网络中断、5xx、参数、鉴权、超时、空响应和图片读取失败不会自动重试。
- 后端图片编辑代理仅接受 GPT Image 2、1-4 张 JPEG/PNG/WebP、单张不超过 15 MB、总请求不超过 64 MB，并强制 `n=1` 与 `b64_json` 响应。
